# Students Life 1.0.11 — анкеты Google Forms

## Что изменилось

В приложении: Новости → Анкеты и формы. Карточки открывают опубликованные Google Forms в браузере. Для списка не нужен аккаунт приложения. Интернет необходим. Ответы остаются в Google Forms; факт заполнения и личность респондента приложение не определяет.

В ManagerSL администратор: Клиентское приложение → Анкеты и формы. Название, описание, ссылка для респондентов (`forms.gle/...` или `docs.google.com/forms/d/.../viewform`), черновик / публикация / скрытие. Ссылки редактора не принимаются. Перед публикацией проверьте форму в приватном окне, доступ для клиентов и собственные настройки Google (сбор email, необходимость входа, повторные ответы).

Старые API опросов и ответы сохранены для ранее установленных версий. Новая версия показывает формы вместо простых голосований. Автоматическая рассылка push при публикации формы не добавлена.

## Сборка из PowerShell

```powershell
cd "C:\Users\ThinkPad\Desktop\projects\students-life-app\mobile"
npx eas-cli login
npx eas-cli build --platform android --profile production
npx eas-cli build --platform ios --profile production
```

Android production создаёт AAB. iOS — подписанную сборку для App Store/TestFlight. Используйте существующие аккаунты и ключи подписи приложения `com.students.life`; не создавайте новое приложение в магазинах. Если EAS запросит APNs key, настройте его в своём аккаунте Apple; приватные ключи не отправляйте в чат.

В `app.json` и package files версия 1.0.11. `eas.json` использует remote version source и autoIncrement. Перед запуском убедитесь, что 1.0.11 ещё не опубликована и remote номера не ниже уже загруженных в магазины. Если сборки выполнялись вне EAS, синхронизируйте последний номер через `npx eas-cli build:version:set`.

Документация: https://docs.expo.dev/build-reference/app-versions/

## Перед публикацией

1. Загрузите AAB во внутреннее тестирование Play Console, iOS — в TestFlight.
2. Опубликуйте свою реальную тестируемую анкету из ManagerSL. На обоих устройствах проверьте список, переход в браузер, заполнение и возвращение. Скрытие анкеты должно убирать её после обновления списка.
3. Проверьте вход, экспресс-заявку, полный профиль, загрузку документа, чат, офлайн-каталог и уведомления на тестовых аккаунтах. Экспорт JavaScript не заменяет проверку устройства.
4. Проверьте доступность ссылок политики/поддержки и корректность деклараций данных для используемых форм. Не собирайте лишние персональные данные.
5. В описании обновления: «Добавлены анкеты Google Forms от Students Life. Улучшено управление формами из кабинета компании».
